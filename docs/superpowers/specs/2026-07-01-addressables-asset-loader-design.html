1. 목적 / 배경

"피격 이펙트가 안 보인다"에서 출발한 조사가 인프라 결정으로 확장됐다: VfxPlayer.SpawnOneShot 의 Instantiate/Destroy(GC) → 공용 풀링 필요(TASK-013) → 풀이 프리팹을 강한참조로 상주 보유하면 안 됨 → 프리팹 약한참조 = Addressables 필요. 착수는 역순이라 Addressables 가 최선행.

본 문서는 그 최선행 조각인 에셋 로더 인프라만 다룬다. 풀링·선언 데이터 모델 상세는 TASK-013 소관, 여기서는 로더가 그것을 떠받치도록 경계와 방향만 확정한다.

4. AssetLoader API

Assets/Scripts/Systems/Assets/AssetLoader.cs · (신규, TASK-015)
▼ 신규
/// <summary> Addressables 에셋을 로드·해제하고 핸들을 추적하는 로더. </summary>
public sealed class AssetLoader
{
    // GUID 기준 중복 로드 방지
    private readonly Dictionary<object, AsyncOperationHandle> handles = new();

    public async UniTask<T> LoadAsync<T>(AssetReference reference) where T : UnityEngine.Object
    {
        object key = reference.RuntimeKey;
        if (handles.TryGetValue(key, out var cached)) return await cached.Convert<T>().ToUniTask();
        var handle = Addressables.LoadAssetAsync<T>(reference);
        handles[key] = handle;          // await 전에 등록 → 동시 로드 레이스 방지
        return await handle.ToUniTask();
    }

    public void Release(AssetReference reference)
    {
        object key = reference.RuntimeKey;
        if (!handles.TryGetValue(key, out var handle)) return;
        Addressables.Release(handle);
        handles.Remove(key);
    }

    public void ReleaseAll()  // 런/씬 종료 시 일괄 해제 → 누수 차단
    {
        foreach (var handle in handles.Values) Addressables.Release(handle);
        handles.Clear();
    }
}
  • 중복 로드 방지: 다른 AssetReference 가 같은 에셋을 가리켜도 RuntimeKey(GUID)로 묶어 핸들 1개.
  • 누수 방지: 모든 핸들을 추적 → ReleaseAll 로 스코프 종료 시 일괄 해제.
  • UniTask: AsyncOperationHandle.ToUniTask(). Coroutine·System.Threading.Tasks 금지.

5. 그룹·라벨 정책

  • 그룹(로드스코프): Boot(앱 시작 로드·상주) / Arena(레벨 진입 로드·퇴장 ReleaseAll). 로컬 빌드만, 각 그룹 Pack Together.
  • 라벨(용도 교차태그): vfx·hit·enemy 등. 한 에셋에 복수 부여. 부분 로드·조회용.
불변식: "그룹 1개 = 로드/해제 스코프 1개". 새 콘텐츠는 스코프 맞는 그룹에 합류, 그룹이 커지면 스코프 축으로만 분할 → 눈덩이 방지. 레벨이 여럿이면 각 레벨을 자기 Arena-스코프 그룹으로(실제로 따로 로드될 때만).

6. 데이터 선언 방향 상세는 TASK-013

예: Assets/Scripts/.../TowerData.cs
public enum EffectType { Hit, Muzzle, Cast, Death }

[System.Serializable]
public struct EffectEntry
{
    public EffectType type;                 // 용도
    public AssetReferenceGameObject asset;  // 그 용도의 프리팹
}

// 스포너 데이터 SO
[SerializeField] private EffectEntry[] effects;

에디터에서 "Hit → Hit_Water" 식 용도별 짝 등록 → PoolManager.PreloadAsync(data) 가 effects 를 열거해 AssetLoader.LoadAsync → 풀 워밍. 런타임 조회는 pool.Get(data.GetAsset(EffectType.Hit)) (동기).

7. 로드 / 해제 흐름

앱 시작      → Boot 그룹 로드 (부트스트랩, 상주)
레벨 시작    → PoolManager.PreloadAsync(레벨 데이터)
                └ 선언 AssetReference 마다 AssetLoader.LoadAsync → 풀 워밍
레벨 진행 중 → pool.Get / Release (동기 핫패스, 로드 없음)
레벨 종료    → PoolManager 풀 정리 + AssetLoader.ReleaseAll (Arena 해제, Boot 유지)
