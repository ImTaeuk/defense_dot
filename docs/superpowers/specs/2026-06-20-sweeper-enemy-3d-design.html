Sweeper 적 3D 교체 설계

설계 스펙 승인 완료 Arena 적 · 2D→3D 전적 교체 · 2026-06-20

1. 목표 / 성공 기준

Arena 적 비주얼을 2D 스프라이트(BillboardSprite)에서 Sweeper 3D 모델(BA_ToonLit)로 전적 교체한다.

  • Move_Ing 애니로 이동 + 이동 방향 Y축 회전
  • 데미지 시 피격 플래시(기존 유지), 사망 시 애니 정지 + dissolve(1초) 후 풀 반환
  • 색상은 스폰마다 Mint/Pink/Yellow 랜덤
성공 기준: 공전 이동·이동방향 회전·피격 플래시·사망 dissolve·풀 재사용(색 재랜덤)이 동작하고, 기존 적 로직(이동전략·풀링·타겟팅) 회귀 없음.

2. 배경 / 현황 (탐색)

  • MonsterActor : ActorBase, IMovableActor, ITargetable, IPoolable. Visual 자식 = SpriteRenderer + Animator + BillboardSprite + Shadow
  • 이동 = ArenaOrbitLogic(원형 공전, 도달 개념 없음). EnemyBehaviorTree가 Tick
  • 사망 = MonsterActor.Resolve() → SetState(Dead) + HandleEnemyKilled → 즉시 풀 반환
  • ITargetable.IsActive = state != Dead → 죽으면 능력 타겟 자동 제외
  • Hovl DissolveNoise.shader는 파티클(Transparent)용 → 스킨드메시 부적합 → BA_ToonLit 확장
  • Sweeper RG: Generic rig, Move_Ing 1클립으로 공전 충분

4. SweeperEnemyVisual.cs

Assets/Scripts/Systems/Enemy/SweeperEnemyVisual.cs
public void Setup(MonsterActor actor);

// 이동 회전: LateUpdate, 위치 delta(Y평면) → LookRotation Slerp
// 피격: actor.OnHit → _HitFlash 0.09s 펄스
// dissolve: PlayDissolve() (UniTask) — Animator.speed=0 + _DissolveAmount 0→1
// 풀 리셋: ResetVisual() — dissolve=0, flash=0, speed=1, 랜덤 색 적용

이벤트 On·핸들러 Handle 컨벤션. material 인스턴스는 SkinnedMeshRenderer 단위.

5. BA_ToonLit 확장

BA_ToonLit.shader · ForwardLit + Outline (의사코드)
// 추가 프로퍼티: _DissolveTex, _DissolveAmount(0..1), _DissolveColor, _HitFlash(0..1)
half n = SAMPLE(_DissolveTex, uv).r;  clip(n - _DissolveAmount);  // 컷아웃
col += _DissolveColor.rgb * step(n - _DissolveAmount, 0.08);   // 경계 발광
col = lerp(col, 1, _HitFlash);                                 // 피격 플래시
기본값 0 → 기존 Aris 머티리얼 영향 없음. 외곽선 패스도 동일 clip으로 동반 소멸.

6. MonsterActor 변경 — Before / After (사망 흐름)

MonsterActor.Resolve()
▼ BEFORE — 즉시 풀 반환
private void Resolve(bool reached) {
    if (resolved) return; resolved = true;
    SetState(ActorState.Dead);
    spawner.HandleEnemyKilled(this);   // 즉시 SetActive(false)
}
▼ AFTER — dissolve 후 지연 반환
private async UniTaskVoid Resolve(bool reached) {
    if (resolved) return; resolved = true;
    SetState(ActorState.Dead);              // 타겟 제외·이동 정지
    if (!reached) await visual.PlayDissolve();   // 1초 dissolve
    spawner.HandleEnemyKilled(this);        // 보상 + 풀 반환
}
// + public event System.Action OnHit;  (TakeDamage 에서 발화)
보상/킬은 HandleEnemyKilled에서 일괄(약 1초 지연되나 dissolve 동안 적이 보여 자연스러움). 비동기는 UniTask. 도달(코어 접촉)은 즉시.

7. 데이터 흐름 / 색상 랜덤

스폰 → ResetVisual(랜덤색, dissolve=0, Move 재생)
이동 → ArenaOrbitLogic 위치 → SweeperEnemyVisual 이동방향 Y회전
피격 → TakeDamage → OnHit → _HitFlash 펄스
사망 → Resolve → Dead(타겟제외·정지) → dissolve 1s → HandleEnemyKilled(보상+풀반환)
재사용 → 풀에서 OnSpawn → ResetVisual(색 재랜덤)
색상: 스폰마다 Mint/Pink/Yellow 머티리얼 랜덤 적용. dissolve/플래시는 material 인스턴스 단위.
