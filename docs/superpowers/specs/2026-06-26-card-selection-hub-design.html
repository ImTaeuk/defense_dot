카드 선택 허브 (Arena A3 코어) 설계

설계 스펙 승인됨 · 리뷰 대기 2026-06-26 · 원작 index.html v608 기준 · TASK-012 A3

1. 목적 / 범위

Arena = "성장하는 자동전투 생존". 코어 능력이 자동 전투하고 플레이어는 kills 누적 → 레벨업 → 카드 3장 선택으로 빌드를 키운다. 이 카드 허브는 A2(능력 실행)·A4(강화)·A5(조합)가 매달리는 중심이다.

범위 = 원작 카드 시스템 5겹 중 코어(①)만. 나머지(럭키·조합·보너스·부가)는 A5/A7/후속으로 분리하되, 본 설계의 데이터/플래그 구조가 확장을 추가만으로 수용한다.

포함: 레벨업 곡선 · 카드 3장(신규/레벨업) · 액티브/패시브 슬롯 반영 · 선택 적용(러너 동기화) · 정지 토글 · uGUI 모달(셰이더+파티클). 제외(뼈대만): 럭키(+2/+3)·조합·보너스·리롤/취소/자동선택·메타 보정.

3. 아키텍처 흐름

데이터 흐름: 처치 → 레벨업 → 카드 모달 → 선택 적용
[적 처치] CombatModel.OnEnemyKilled(reward)
   ▼
LevelModel  kills++ → 곡선 도달 시 level++, pendingLevelUps++ → OnLevelUp
   ▼
CardSelectionPresenter
   1) CardChoiceGenerator.Generate(loadout, pool, config) → List<CardChoice>
   2) choices 비면 무모달(레벨만 부여), 아니면 ↓
   3) View.Show(choices) + (config.pause면) Time.timeScale = 0
   ▼
CardSelectionView (uGUI, 셰이더+파티클)  →  OnCardSelected(index)
   ▼
CardSelectionPresenter
   4) CoreAbilitySystem.AddAbility(data) / LevelUpAbility(instance)  // 러너 동기화
   5) View.Hide() + Time.timeScale = 1 (게임이 Playing일 때만)
   6) pendingLevelUps > 0 면 3)으로 재진입
설계 원칙: 로직(생성·적용) ↔ 표현(View·셰이더·파티클) 분리, 티어 색/연출은 데이터(CardTierSet)로 구동 → 원작 하드코딩 9티어를 데이터 한곳에서 관리, 후속 겹은 데이터/플래그 추가로 확장.

5. 정지(Pause) 처리

  • config.pauseOnCardSelect 시 모달 표시 → Time.timeScale = 0, 선택 후 1 복구
  • 소유권 충돌 방지: GameResultPresenter도 timeScale을 만진다 → 카드 프레젠터는 게임이 Playing일 때만 1로 복구. 종료(GameOver/Victory) 시엔 결과 프레젠터가 0을 잡으므로 카드 프레젠터는 복구 안 함(모달만 숨김)
  • GamePhase에 Paused 추가하지 않음(timeScale 방식 — 기존 합의)

6. 연출(VFX) — 방식1

  • 셰이더(주력): CardBackground.shader 손코딩(그라데이션·네온 글로우, 향후 무지개/펄스). MCP manage_shader/머티리얼로 저작
  • 파티클: Shuriken ParticleSystem을 execute_code(C#)로 모듈 구성. 스크린스페이스 배치
  • VFX Graph 미사용(MCP 저작 불가) — 코어 연출은 셰이더+파티클로 충분
  • 검증: 빌드 후 스크린샷으로 확인·반복 튜닝. 코어 티어(New/Upgrade)부터 풀 폴리시, 럭키/조합 연출은 CardTierSet 자리에 후속 채움

7. 엣지 케이스 / 오류 처리

케이스처리
후보 0장(전부 보유+max, 풀 소진)모달 미표시, 레벨만 부여 + 경고 로그
후보 < choiceCount가능한 장수만 표시(3 미만)
레벨업 다중 큐(비정지 연속)PendingLevelUps로 순차 처리(선택 후 재진입)
신규 액티브 추가러너 Equip 호출로 즉시 틱 반영(누락 시 동작 안 함)
게임 종료 중 모달모달 숨김, timeScale 복구는 결과 프레젠터에 위임
Dispose/씬 종료구독 해제 + timeScale=1 안전 복구

8. 테스트 전략

#시나리오기대
1EditMode — LevelModel 곡선(레벨별 KillsToNextLevel), 다중 레벨업/Pending 누적곡선·카운터 정확
2EditMode — CardChoiceGenerator: 슬롯 가득→레벨업만, 풀 소진→fewer/empty, 3장 중복 없음, early/late 비율 경계규칙대로 생성
3PlayMode — kills 주입→OnLevelUp→모달→선택→Loadout 반영(신규 Equip / 레벨 증가)빌드 반영 + 틱 동작
4PlayMode — 정지 토글 on/off 시 Time.timeScale 0↔1정지·복구 정확

9. 후속 / 확장 지점 (이번 미포함)

  • ② 럭키: enableLucky on + Generator lucky roll + CardChoice.tier=Lucky/SuperLucky + 셰이더 무지개/파티클
  • ③ 조합(A5): combo 후보(재료2 MAX) + CardAction.Combo 적용(재료 소진→상위)
  • ④ 보너스(A7): CardAction.Bonus* + 메타(스타더스트/점수/어센던트)
  • ⑤ 부가: 리롤 / 취소(골드 환불·다음 비용↑) / 자동선택 타이머
  • 메타 보정(levelUpMul/levelUpFast/luckyChanceBonus)을 Config/런 상태에 연결
