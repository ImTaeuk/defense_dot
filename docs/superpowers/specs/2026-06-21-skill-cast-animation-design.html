스킬 소유 애니메이션 + 이벤트 발사 설계

설계 스펙 승인 완료 Arena 코어(Aris) 시전 · 2026-06-21

1. 목표 / 성공 기준

각 스킬이 자기 시전 애니를 소유하고, 시전 시 Tower Animator의 Attack 슬롯을 오버라이드해 재생한다. 투사체 발사를 애니 클립의 AnimationEvent 프레임에 동기화해 타이밍을 100% 일치시킨다.

성공 기준: Shot 시전 시 Aris가 전용 모션을 재생하고, 모션의 발사 프레임에 정확히 투사체가 나간다. 애니 없는 스킬은 즉시 발사(현 동작 유지). EditMode 회귀 없음.

2. 현재 동작 (문제)

  1. ProjectileAbilityData.Tick 가 쿨다운→FindNearest→즉시 발사 + ctx.OnFired 발화
  2. CoreAbilitySystem.OnAbilityActivated → ArisTowerVisual.HandleAbilityActivated → SetTrigger("Attack")
  3. → 모든 능력이 단일 Attack 트리거 공유, 발사와 모션 임팩트 프레임이 어긋남
핵심 원인: 발사 시점이 Tick(즉시)에 고정되어 애니와 분리됨. 발사를 애니 이벤트로 옮겨야 일치한다.

3. 아키텍처 / 신규·변경

구분파일책임
신규ICastHost.csRequestCast(...)bool + NotifyFireFrame() (CoreAbilitySystem)
신규ICastReceiver.csPlayCast(clip) + IsCasting (ArisTowerVisual)
변경AbilityContext.csOnFired 제거 → ICastHost Cast
변경ActiveAbilityData.cscastAnimation + 공통 Tick + abstract Fire
변경Projectile/AreaWaveAbilityDataTick 본문 → Fire
변경CoreAbilitySystem.csICastHost 구현·pending 발사·castReceiver
변경ArisTowerVisual.csICastReceiver·OnFireFrame·AnimatorOverride
신규Shot 시전 .animAttack 클립 복제 + OnFireFrame 이벤트

4. 능력 실행 모델 — Before / After

ActiveAbilityData / ProjectileAbilityData
▼ BEFORE — Tick 즉시 발사
// ProjectileAbilityData.Tick
if (!TickCooldown(self,dt)) return;
target = Finder.FindNearest(...);
fx = Effects.Spawn(...); fx.Activate(...);   // 즉시 발사
ctx.OnFired?.Invoke();   // → 단일 Attack 트리거
ResetCooldown(self,ctx);
▼ AFTER — Tick 시전 / 이벤트 Fire (Template Method)
// ActiveAbilityData.Tick (공통)
if (!TickCooldown(self,dt)) return;
target = ctx.Finder.FindNearest(ctx.Origin, Range);
if (target == null) return;
if (castAnimation != null && ctx.Cast != null) {
    if (!ctx.Cast.RequestCast(this, self, target, castAnimation)) return; // 시전중 대기
} else Fire(ctx, self, target);   // 애니 없으면 즉시
ResetCooldown(self, ctx);
// abstract Fire(ctx,self,target): Projectile=투사체 / AreaWave=존

5. 시전 흐름 (CoreAbilitySystem ↔ ArisTowerVisual)

Tick → ctx.Cast.RequestCast(skill, self, target, clip)
  CoreAbilitySystem: IsCasting 이면 false(대기) / 아니면 pending 보관 + receiver.PlayCast(clip)
  ArisTowerVisual.PlayCast: override["...Normal_Attack_Ing"] = clip + SetTrigger(Attack)
애니 진행 → AnimationEvent("OnFireFrame") → ArisTowerVisual.OnFireFrame()
  → core.NotifyFireFrame() → pending.skill.Fire(ctx, self, target)   // 정확한 발사
애니 종료 → IsCasting = false (다음 시전 허용)
발사 주체가 Tick(즉시) → AnimationEvent로 이동해 모션과 발사가 일치. 클립 키 Aris_Original_Normal_Attack_Ing 를 AnimatorOverrideController로 스킬 클립과 교체.

6. AnimationEvent 부착

Aris FBX 클립은 default 임포트(31개)라 원본에 이벤트를 못 답니다. Attack 클립을 .anim으로 복제 → 발사 프레임에 functionName="OnFireFrame" 이벤트 추가 → Ability_Shot.castAnimation에 할당합니다(원본 FBX 무수정).

안전장치: 클립에 OnFireFrame 이벤트가 없으면 PlayCast 시 즉시 Fire로 폴백 — 발사 누락 방지.

7. 디폴트 결정

항목결정
동시 시전시전 중이면 다른 애니 스킬은 쿨다운 유지·대기. 애니 없는 스킬은 항상 즉시
타겟시전 시작 시 확정, 발사 프레임에 죽었으면 재탐색→없으면 전방(유도탄)
오비탈(상시)IAbilityLifecycle, Tick 미사용 → 영향 없음
