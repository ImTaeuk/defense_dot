Blue Archive 풍 Toon Lit 셰이더 설계

설계 스펙 승인 완료 Aris 모델 전용 · 실용형 · 2026-06-20

1. 목표 / 성공 기준

Aris 모델(BA 전투용 SD/데포르메 3D 모델)에 Blue Archive 풍 셀셰이딩 룩을 입힌다. albedo 텍스처는 그대로 두고 명암 처리(셰이딩)만 BA 풍으로 교체한다.

  • 이 모델에만 격리 적용 — 외부 원본 FBX·텍스처·타 모델 머티리얼 무수정
  • 사용자 확정: "블루아카이브 느낌만 날 수 있다면 뭐든 좋다" → 실용형 범위
성공 기준: 프리뷰(블룸 off)에서 ① 2~3톤 셀 음영(채색 그림자) ② 외곽선 ③ 빛 쪽 실루엣 림라이트 ④ 머리카락 하이라이트가 보이고, "평범한 URP 디폴트 + 툰" 수준의 깔끔함을 유지한다.

2. 배경 조사 (judge 웹 조사)

  • BA 전투 화면은 데포르메(SD) 3D 모델을 사용 — 우리 Aris 모델이 정확히 그 대상
  • BA 공식 셰이더 1차 자료는 비공개 → 검증된 애니 NPR 표준 기법으로 재현
  • 견고한 구현은 전부 HLSL(ShaderGraph 아님), URP 17 직접 작성
  • 모델 동봉 mask 텍스처가 BA 셰이더용 채널 데이터로 확인 (아래 표)
텍스처관찰된 내용1차 활용
Face_Mask코 그림자 SDF 곡선후속(정밀형)
Hair_Mask머리카락 가닥 음영/스펙 영역보조(선택)
Hair_Spec분홍/무지개 컬러 하이라이트적극 사용
Body_Mask부위 분할후속(정밀형)
mask 채널 정확 의미는 웹 미문서화 → 실측 영역. 실용형 1차는 Hair_Spec 중심 + 파라미터로 BA 느낌을 잡고, Face_Mask SDF·정밀 채널은 후속으로 분리.

3. 아키텍처 / 파일 구조

구분경로책임
신규 BlueArchive/Aris/Shaders/BA_ToonLit.shader URP HLSL 툰 라이팅 + 외곽선 2패스
수정 BlueArchive/Aris/Materials/*.mat (8개) 셰이더를 BA_ToonLit으로 교체, _BaseMap 유지
유지 Aris_Original.fbx (리맵) 이미 위 8개 .mat을 가리킴 → 자동 적용
격리: BA_ToonLit은 이 8개 머티리얼만 사용하고 렌더러 전역 설정을 바꾸지 않는다 → 타 모델 무영향.

4. 셰이더 패스 설계

Pass 1 — ForwardLit (UniversalForward)

BA_ToonLit.shader · ForwardLit (의사코드)
half NdotL = dot(N, L);
half half_lambert = NdotL * 0.5 + 0.5;

half cel = smoothstep(_ShadowThreshold - _ShadowSmooth,
                     _ShadowThreshold + _ShadowSmooth, half_lambert * shadow);
half3 lit    = albedo;
half3 shadow = albedo * _ShadowColor;            // 채색 그림자
half3 baseCol = lerp(shadow, lit, cel);

half fresnel = pow(1 - saturate(dot(N, V)), _RimPower);
half3 rim = fresnel * saturate(NdotL) * _RimIntensity * _RimColor;

half3 hairSpec = tex(_SpecMap, uv).rgb * pow(saturate(NdotH), 1)
                 * _SpecColor * _SpecIntensity;   // Hair_Spec
return (baseCol + rim + hairSpec) * lightColor;

셀 음영은 half-lambert를 smoothstep으로 단계화하고 메인 라이트 그림자를 곱한다. 채색 그림자는 albedo에 _ShadowColor(기본 푸른/보라 틴트)를 곱해 BA 특유의 색감을 낸다.

Pass 2 — Outline (백페이스 헐, Cull Front)

BA_ToonLit.shader · Outline (의사코드)
// 정점을 노멀 방향으로 확장
float3 posOS = IN.positionOS + IN.normalOS * _OutlineWidth;
// Cull Front 로 뒷면만 그려 외곽선화
return _OutlineColor;   // 단색 외곽선

균일 두께(파라미터). 하드엣지에서 외곽선이 갈라지면 스무딩 노멀 보정을 검토한다(모델 노멀 상태 확인 후 결정).

5. 셰이딩 변화 — Before / After

현재(복구된 URP/Lit) 대비 BA Toon 의 셰이딩 차이를 의사코드로 비교한다.

▼ BEFORE — URP/Lit (현재 복구 상태)
// PBR 연속 명암
half3 col = albedo * (NdotL_continuous) + specularPBR;
// 명암이 부드럽게 연속 → 툰 느낌 없음, 반짝임 존재
▼ AFTER — BA Toon Lit
half cel = smoothstep(t-s, t+s, halfLambert * shadow);  // 2~3톤 단계화
half3 col = lerp(albedo*_ShadowColor, albedo, cel);     // 채색 그림자
col += rim;        // Fresnel x NdotL 림라이트
col += hairSpec;   // Hair_Spec angel-ring
// + 별도 패스 외곽선
albedo(텍스처 색)는 양쪽 동일. 달라지는 것은 명암을 연속 → 셀 단계화, 그림자에 색, 림/머리 하이라이트/외곽선 추가.

7. 텍스처 · 라이팅 매핑

입력매핑
_BaseMap각 부위 albedo (Body/Face/EyeMouth/Hair/Halo/Weapon — 매칭 완료)
_SpecMapAris_Original_Hair_Spec (Hair 머티리얼만)
라이팅ArenaScene 메인 디렉셔널 라이트(현 intensity 1.3) 방향/색

탑다운 각도에서 음영이 약하면 _ShadowThreshold로 조정한다.

8. 검증 시나리오

셰이더는 단위 테스트 대상이 아니므로 컴파일 + 시각 검증으로 확인한다.

#시나리오기대
1셰이더 컴파일에러 없음 (read_console)
2프리뷰 캡처(블룸 off)셀 음영·외곽선·림·머리 하이라이트 가시
3부위별 파라미터 튜닝얼굴 그림자 약하게, 머리 spec 강조
4타 모델 영향무영향 (격리 확인)

9. 범위 외 (후속 / 정밀형) · 파일 요약

  • Face_Mask 기반 SDF 얼굴 그림자(코 그림자 라이트 스윕)
  • Body/Hair_Mask 정밀 채널 실측·활용
  • 추가 라이트 다중 처리, 정점 컬러 외곽선 두께, matcap 머리 하이라이트
