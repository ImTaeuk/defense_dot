일시정지 중 홀로그램 *Speed 복구 — Unscaled Time 주입

설계 문서 설계 승인 완료 TASK-014 B-0 · 2026-06-29

1. 제보 요지

"머티리얼의 ShineSpeed 같은 게 TimeScale 을 카드 고르는 중에 0으로 두는 바람에 작동을 안 하는 게 문제였잖아."

핵심 원인: 홀로그램 셰이더가 _Time.y(scaled time)로 애니메이션하는데, 카드 모달이 Time.timeScale = 0으로 게임을 멈춰 _Time이 정지 → 모든 *Speed가 무효가 된다.

2. 현재 동작 (재현 경로)

  1. 처치 누적 → 레벨업 트리거, 카드 선택 모달 표시
  2. CardSelectionPresenter.cs:58 가 if (config.pauseOnCardSelect) Time.timeScale = 0f; 로 게임 정지
  3. Unity 엔진이 _Time.y 갱신을 멈춤 (scaled time = Time.time 기반)
  4. 카드 포일 셰이더 HologramFoilTinted.shader:157 의 t = _Time.y 가 고정 → _RainbowSpeed·_ShineSpeed 곱이 정지
  5. 결과: 카드는 멈춘 홀로그램으로만 표시 — *Speed 를 올려도 변화 없음

3. 근본 원인

Assets/Shader/HologramFoilTinted.shader · frag() L153-193
fixed4 frag(v2f IN) : SV_Target
{
    float2 uv = IN.texcoord;
    ...
    float t = _Time.y;   // ← timeScale=0 이면 _Time 정지
    ...
    float rainbowPhase = ... + t * _RainbowSpeed;
    ...

한 줄 t = _Time.y 가 무지개 위상·포일 밴드·샤인 이동 세 곳에 모두 재사용된다. _Time 은 scaled time 이라 일시정지 중 증가를 멈추고, 카드 모달은 항상 일시정지 상태에서만 표시되므로 이 한 줄이 모든 *Speed 를 무력화한다. Unity 공식 문서상 unscaled time 을 제공하는 빌트인 셰이더 변수는 존재하지 않는다.

방증: CardSelectionView.cs:98 은 Time.unscaledDeltaTime 으로 C# 등장 연출을 정지 중에도 돌린다 → C# 은 unscaled, 셰이더만 scaled 라는 시간 기준 불일치가 본 문제의 본질.

4. 기획 요구사항 (사용자 확정)

  • 일시정지(timeScale=0) 중에도 홀로그램 *Speed 가 정상 작동할 것 — "지금 수정" 선택
  • 수정 범위: 홀로그램 셰이더 6개 일괄 — 카드(HologramFoilTinted) + 나머지 5개 UI 홀로그램 모두 전환 (재발 방지)
  • 주입 방식: 글로벌 Shader.SetGlobalFloat — 머티리얼별 처리는 등급 머티리얼이 여러 개라 비채택

5. 설계 원칙 — 컨벤션 정렬

통일감 있는 구현을 위해 Unity 표준 기법과 프로젝트 내 선례 두 레퍼런스에서 사상을 추출했다.

레퍼런스위치차용 포인트
Unity 표준 (unscaled 주입) Unity Manual / Discussions 커스텀 글로벌 프로퍼티에 Time.unscaledTime 매 프레임 주입 → 셰이더가 _Time.y 대신 사용 (빌트인 unscaled 부재의 표준 우회)
프로젝트 선례 CardSelectionView.cs:98 Time.unscaledDeltaTime 으로 정지 중 연출 유지 — "일시정지 UI 는 unscaled 로 움직인다" 는 이미 확립된 의도
결합 결론: 이미 C# 측은 unscaled 로 동작하도록 설계돼 있으므로, 셰이더도 같은 시간 기준(unscaled)으로 맞추는 것이 일관된 수정이다. 글로벌 주입 드라이버 1개로 6개 셰이더를 동시에 정렬한다.

레퍼런스 ① Unity 표준 — 글로벌 unscaled 주입

패턴 (judge 웹 검증 · Unity Manual: Built-in shader variables)
// C# — 매 프레임 글로벌 주입
Shader.SetGlobalFloat("_UnscaledTime", Time.unscaledTime);

// Shader — _Time.y 대신 커스텀 글로벌 사용
float _UnscaledTime;
float t = _UnscaledTime;   // scaled _Time.y 대체

Unity 공식: "There is no built-in variable that provides access to unscaled time." → 커스텀 글로벌 주입이 검증된 표준 해법.

(1) UnscaledTimeShaderDriver — 신규 컴포넌트 신규

// 부팅 시 자동 생성 — 배선 불필요. 매 프레임 unscaled time 글로벌 주입.
public sealed class UnscaledTimeShaderDriver : MonoBehaviour
{
    private static readonly int UnscaledTimeId = Shader.PropertyToID("_UnscaledTime");

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
    private static void Bootstrap()
    {
        GameObject go = new GameObject("[UnscaledTimeShaderDriver]");
        go.hideFlags = HideFlags.HideAndDontSave;
        DontDestroyOnLoad(go);
        go.AddComponent<UnscaledTimeShaderDriver>();
    }

    private void Update()
        => Shader.SetGlobalFloat(UnscaledTimeId, Time.unscaledTime);
}

7. 영향 범위 및 부수 효과

항목분석
게임 중(timeScale=1) 표현 회귀 없음. unscaledTime ≈ time 이라 기존과 동일하게 흐름
일시정지 중 홀로그램 정상 작동. 카드 모달·결과 화면에서 *Speed 살아남
성능 비용 미미. 매 프레임 SetGlobalFloat 1회
배선·프리팹 변경 없음. RuntimeInitializeOnLoadMethod 자동 생성
에디터 비플레이 머티리얼 프리뷰 프리뷰만 정지 (글로벌 미주입). 게임 플레이 무관 — 허용 트레이드오프
