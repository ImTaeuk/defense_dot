Aris 코어 타워 통합 설계

설계 스펙 승인 완료 Arena 코어 타워 · 풀 연출 · 2026-06-20

1. 목표 / 성공 기준

Arena 코어 타워 비주얼을 Aris 3D 모델(BA_ToonLit 적용)로 대체하고, FBX 내장 애니메이션으로 상태를 연동한다.

  • 대기·공격·위기·파괴·승리 애니 연동 (풀 연출)
  • 최근접 적을 향해 Y축 회전 — "조준" 연출
  • 코어 타워에만 격리 — 외부 원본·타 모델·HD-2D 적 렌더링 무영향
성공 기준: Play에서 ① Idle ② 능력 발동 시 Attack ③ 적 추적 회전 ④ 코어 HP 저하 Panic·파괴 Death·웨이브 클리어 Victory 전환 확인.

2. 배경 / 현황 (탐색)

  • 코어 타워 = ArenaModeBootstrap.SpawnCenterTower 가 TowerData 프리팹 + TowerActor + CoreAbilitySystem 생성. 현재 비주얼은 2D 스프라이트 빌보드.
  • 적/액터 = BillboardSprite + ActorAnimatorBinder (2D 스프라이트·4방향) → Aris(3D)에 부적합
  • CoreAbilitySystem 능력 발동 이벤트 없음 → 추가 필요
  • Aris FBX: rig=Generic, 내장 클립 31개 → 리타겟 불필요, 자체 본으로 직접 재생

5. ArisTowerVisual.cs 인터페이스

Assets/Scripts/Systems/Mode/ArisTowerVisual.cs
public void Setup(CoreAbilitySystem core, TargetFinder finder,
                  GameFlowModel flow, CoreModel coreHp);

core.OnAbilityActivated += () => animator.SetTrigger("Attack");
// Update: 최근접 적 향해 Y축 Slerp 회전 (적 없으면 카메라 정면)
// coreHp.OnCurrentChanged → LowHP bool / 0 도달 → SetTrigger("Death")
// flow 승리 → SetTrigger("Victory")

이벤트 On·핸들러 Handle 접두사 컨벤션을 따른다.

6. CoreAbilitySystem / AbilityContext 변경 — Before / After

AbilityContext.cs · CoreAbilitySystem.cs (의사코드)
▼ BEFORE
// AbilityContext: 발사 통지 수단 없음
public AbilityContext(host, origin, finder, modifiers, effects) { ... }
// CoreAbilitySystem: 외부 이벤트 없음
▼ AFTER
// AbilityContext: 발사 콜백 추가
public readonly System.Action onAbilityFired;
public AbilityContext(host, origin, finder, modifiers, effects, onAbilityFired) { ... }
// 이산 능력 발사 시: ctx.onAbilityFired?.Invoke();
// CoreAbilitySystem:
public event System.Action OnAbilityActivated;   // onAbilityFired 를 중계
상시 오비탈은 통지하지 않는다. 이산 능력(샷/AOE)의 실제 발사 시점만 Attack 트리거로 연결.

7. ArenaModeBootstrap 변경 수정

  • SpawnCenterTower: 기존 코어 2D 스프라이트 렌더러 비활성화(비주얼 루트 숨김)
  • Aris_CoreTower.prefab 을 코어 타워 자식으로 Instantiate
  • ArisTowerVisual.Setup(coreAbilitySystem, targetFinder, flow, coreModel) 호출

8. 데이터 흐름 / 디폴트

적 발생 → TargetFinder → ArisTowerVisual 이 최근접 적 향해 Y회전
능력 쿨다운 → Tick 발사 → onAbilityFired → OnAbilityActivated → Animator "Attack"
코어 HP↓ → LowHP=true → Panic / 파괴 → "Death" / 웨이브 클리어 → "Victory"
항목디폴트
스케일globalScale 170(~1.8m) 유지, 프리뷰 미세조정
Attack 트리거이산 능력 발동마다(연속 시 crossfade), 오비탈 제외
회전Y축만 Slerp, 적 없으면 카메라 정면
빌보드Aris 3D → 미사용, 기존 코어 스프라이트 숨김
