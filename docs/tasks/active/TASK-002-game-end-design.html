게임 종료·결과·재시작 설계 (TASK-002)

설계 제안서 검토 대기 플레이 루프 클로징 · 2026-06-11

1. 제보 요지

"시작 → 플레이 → 다시 시작"의 완결 루프가 종료에서 막다른 길이다. 게임이 끝나도 결과 UI·재시작이 없고, Arena 는 웨이브를 다 막으면 잘못 '승리'한다.

핵심: GameFlowModel.OnPhaseChanged 는 이미 발행되는데 구독자가 0 — 결과 UI 는 "구독자 한 명 + 패널"이면 닫힌다. Arena 만 웨이브 클리어 승리를 막으면 끝.

2. 현재 동작 (재현 경로)

  1. 승/패 도달 → GameManager 가 Flow.SetPhase(GameOver/Victory) → OnPhaseChanged 발행
  2. 구독자 0 (GameFlowModel.cs:35) → 화면 변화 없음, SceneManager.LoadScene 호출 0
  3. 승리 트리거: EnemySpawner.cs:76 이 웨이브 소진 시 MarkWaveCleared() → Wave.OnWaveCleared → Victory. 모드 무관 → Arena 도 잘못 승리

4. 기획 요구사항 (사용자 확정)

  • 결과 패널(승/패) + 재시작 — 재시작은 현재 씬 재로드, 종료 시 Time.timeScale=0 정지
  • 결과 UI 는 승/패 메시지 + 재시작 버튼만 (메인 메뉴는 TASK-008 타이틀)
  • Arena 종료 처리 = "최소 보정 포함" 선택 — Arena 는 승리 안 함 + 무한 스폰, 수용 한계 초과로만 패배
