인게임 HUD 통합 — 코드 수정안

제안서 진행 중 TASK-001 A · 설계 확정 · 2026-06-06

1. 제보 요지

“UI 프리팹 구성은 끝났고, UI 를 통합해 단일 HUD 로 만들고 싶다.” 현재 두 모드(Grid 타워 디펜스 / Arena 코어 디펜스)의 HUD 가 uGUI HUDView 와 UI Toolkit WaveHUDPresenter 로 분열돼 있어 웨이브 표시 중복·MVP 비대칭·HUDView NRE 가 누적됐다.

핵심 결론: 게임 씬 내 HudBootstrap 미디에이터로 단일 통합 HUD 를 구성하고, 적 게이지는 원작 충실(살아있는 적 / 수용 한계, 위험 채움)로 두 모드를 통일한다. 도메인 모델·9개 EditMode 테스트는 불변.

2. 현재 동작 (재현 경로)

  1. GameManager.cs:56-67 가 도메인 POCO 모델(Economy/Core/Wave)을 생성·초기 통지
  2. GameManager.cs:90-95 가 hudView 면 HUDPresenter 인라인 생성, waveHud 면 waveHud.Bind(Wave) 호출 — 두 갈래로 분기
  3. HUDView.cs:23-33 이 3개 TMP 텍스트(골드/웨이브/체력)를 직접 갱신
  4. WaveHUDPresenter.cs:64-72 가 UI Toolkit Label 로 웨이브·잔여 적을 별도 표시 (웨이브 중복)
  5. Play 시 AreanaScene 의 HUDView 인스턴스 TMP 필드가 모두 미할당(fileID:0) → NRE 잠재

구조적 원인: ① 웨이브 표시가 HUDView 와 WaveHUDPresenter 양쪽에 중복. ② WaveHUDPresenter 는 MonoBehaviour 가 UIDocument 를 직접 Q<Label> 조작 — View/Model 경계 없는 MVP 비대칭.

4. 기획 요구사항 (사용자 확정)

  • 레이아웃 B(코너 분산): 좌상단 골드·체력 / 우상단 라운드·적 수
  • HUD 구조·컴포넌트는 두 모드 공통, 데이터 바인딩(capacity)만 차등
  • RoundView 표기 = 라운드 {current}/{total}
  • (원본 충실) 적 = 살아있는 적 / 수용 한계(maxAlive), 위험 시 채워지는 게이지 + 색상 임계 — 두 모드 공통 (근거 index.html:16160·16180)
  • 아키텍처 = 게임 씬 내 HudBootstrap 미디에이터 (별도 UI 씬 X · 싱글톤 X · SO 채널 X)
  • 이번 작업 = Grid HUD 완성 / Panel_Arena 프리팹은 designer 후속(Arena capacity 코드는 포함)
  • 코딩 스타일(추가 지시): 유효성 검사는 IsValid() bool 반환 사용(Validate 대신) · 라이프사이클 함수(Awake/OnDestroy 등)에 람다(=>) 금지, 블록 본문 사용

6. 해결 방안 — 변경 사항

(1) 하위 View 4종 — GoldView / HealthView / RoundView / EnemyCountView 신규

각 코너 위젯을 단일 책임 MonoBehaviour 로 분리. 자기 TMP/Image 만 직렬화하고 도메인을 모른다. 유효성은 IsValid() bool 반환, Awake 는 블록 본문(람다 금지).

Assets/Scripts/UI/Views/GoldView.cs (신규)
▼ 신규
using UnityEngine;
using TMPro;

namespace DefenseDot.UI.Views
{
    /// <summary>골드 수치를 표시하는 하위 View.</summary>
    public class GoldView : MonoBehaviour
    {
        [SerializeField] private TextMeshProUGUI goldText;

        private void Awake()
        {
            if (!IsValid()) Debug.LogError($"[GoldView] goldText 미할당: {name}", this);
        }

        public void SetGold(int gold)
        {
            if (goldText == null) return;
            goldText.text = gold.ToString();
        }

        private bool IsValid() => goldText != null;
    }
}
Assets/Scripts/UI/Views/EnemyCountView.cs (신규 · 원작 충실)
▼ 신규
using UnityEngine;
using UnityEngine.UI;
using TMPro;

namespace DefenseDot.UI.Views
{
    /// <summary>생존 적 수 / 수용 한계 + 위험 게이지.</summary>
    public class EnemyCountView : MonoBehaviour
    {
        [SerializeField] private TextMeshProUGUI countText;
        [SerializeField] private Image fillBar;
        [SerializeField] private Color normalColor = new Color(1f, 0.72f, 0.42f);
        [SerializeField] private Color warnColor   = new Color(1f, 0.53f, 0.33f);
        [SerializeField] private Color dangerColor = new Color(1f, 0.20f, 0.27f);

        private void Awake()
        {
            if (!IsValid()) Debug.LogError($"[EnemyCountView] 참조 미할당: {name}", this);
        }

        public void SetEnemyCount(int alive, int capacity)
        {
            float ratio = capacity > 0 ? alive / (float)capacity : 0f;
            if (countText != null) countText.text = $"잔여 적 {alive} / {capacity}";
            if (fillBar == null) return;
            fillBar.fillAmount = ratio;                               // 위험 방향 채움
            fillBar.color = ratio > 0.75f ? dangerColor : ratio > 0.5f ? warnColor : normalColor;
        }

        private bool IsValid() => countText != null && fillBar != null;
    }
}

HealthView(SetHealth(cur,max,ratio)), RoundView(SetRound(cur,total) → 라운드 N/M)도 동일 골격(블록 본문 Awake + IsValid())을 따른다.

(4) HudBootstrap — 미디에이터 신규

Assets/Scripts/UI/InGame/HudBootstrap.cs (신규)
▼ 신규
namespace DefenseDot.UI.InGame
{
    /// <summary>HUD 진입점·미디에이터. 합성 루트가 주입한 모델로 Presenter 구성.</summary>
    public class HudBootstrap : MonoBehaviour
    {
        [SerializeField] private HUDView hudView;
        private HUDPresenter presenter;

        public void Inject(EconomyModel economy, CoreModel core, WaveModel wave, int enemyCapacity)
        {
            presenter = new HUDPresenter(hudView, new HUDModel(), economy, core, wave, enemyCapacity);
            presenter.Initialize();
        }

        private void OnDestroy()        // 블록 본문(람다 금지)
        {
            presenter?.Dispose();
        }
    }
}

GameManager 는 HudBootstrap 만 알고 HUDView/Presenter 는 모른다(God Object 회피). OnDestroy 는 사용자 규칙대로 람다 대신 블록 본문.
