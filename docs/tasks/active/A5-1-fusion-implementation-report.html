A5-1 능력 합성(Fusion) — 구현 완료 보고 + 플레이 검증 가이드

구현 완료 자동 검증 통과 EditMode 152/152 · 2026-07-13

1. 작업 요지 & 결론

원작 dot-defense 의 "능력 조합"을 우리 프로젝트의 타워 분리 구조에 맞춰 재해석했다. 두 재료 능력을 각각 MAX 레벨까지 키우면, 레벨업 카드 허브에 합성(Fusion) 카드가 보라 티어로 등장한다. 선택 시 두 재료를 소비하고 결과 능력을 지급한다. 합성 목록은 타워(캐릭터)마다 다른 계보 테이블(FusionRecipeSet)이 결정한다.

결론: 데이터(TowerData.fusionLineage)와 로직(FusionResolver·CardChoiceGenerator·CardChoiceApplier)을 완전히 분리해 배선 완료. 코드 컴파일 클린, EditMode 152/152 통과. 남은 것은 플레이(PlayMode) 체감 검증뿐.

2. 합성 동작 흐름 (런타임 경로)

  1. 플레이어가 코어 타워의 재료 능력 2종을 카드로 각각 MAX 레벨까지 강화
  2. 레벨업 발생 → CardSelectionPresenter.cs:60 가 generator.Generate(..., lineage) 호출
  3. CardChoiceGenerator 가 FusionResolver.Available(loadout, lineage) 로 성립한 합성만 추림 (재료 2종 모두 소유·MAX, 결과 미소유일 때만)
  4. 성립 시 Fusion 티어 카드를 선택지 앞쪽에 배치해 표시
  5. 선택 시 CardChoiceApplier 의 Fuse 분기가 결과 이펙트 예열 → 재료 2종 RemoveAbility → 결과 AddAbility
계보 주입 경로: TowerData.fusionLineage → ArenaModeBootstrap.FusionLineage → GameManager → GameContext.FusionLineage → CardSelectionPresenter. 타워를 바꾸면 계보도 함께 바뀐다(캐릭터별 루트).

4. 생성한 데이터 에셋 (데모 계보)

새 능력을 날조하지 않고 실존 능력만 엮어 즉시 검증 가능한 데모 계보를 구성했다. 코어 타워의 스타터가 Ability_Shot·Ability_Orbital 이므로 이 둘을 재료로 잡으면 처음부터 소유 상태라, MAX 강화만 하면 합성이 성립한다.

에셋내용
Assets/Data/Fusion/Aris_FusionLineage.asset 레시피 1건: Ability_Shot + Ability_Orbital → Ability_AreaWave
Assets/Data/Towers/TowerData.asset (Tower Test = 코어) fusionLineage 필드에 위 계보 배선 완료
재료 Shot·Orbital 모두 maxLevel = 5, 셋 다 ActiveAbilityData. 결과 AreaWave는 스타터가 아니므로 초기 미소유 → "소유·MAX·결과 미소유" 3조건 자연 충족.

6. ★ 플레이(PlayMode) 검증 가이드 — 당신이 해줄 것

아래는 사람의 눈·손이 필요한 체감 항목이다. 코드/데이터 정합은 위에서 자동 검증했으므로, 여기서는 "실제로 재미있고 자연스럽게 작동하는가"를 본다.

#검증 시나리오기대 / 확인 포인트
1 합성 카드 등장 — 플레이 시작 후 Shot·Orbital을 카드로 각각 레벨 5(MAX)까지 강화 둘 다 MAX가 된 다음 레벨업에서 AreaWave 합성 카드가 보라 티어로 등장
2 합성 카드 체감 — 합성 카드가 다른 카드와 시각적으로 구분되는지 보라 색/라벨 readability, "재료 2개 소비" 의미가 직관적으로 읽히는지
3 합성 적용 결과 — 합성 카드 선택 Shot·Orbital 사라지고 AreaWave 발동 — 결과 능력의 실전 동작·연출이 정상인지
4 중복 방지 — 합성 후 같은 재료가 다시 카드로 나오는지 이미 소비된 재료로 같은 합성 재등장 안 함 (결과 소유 시 제외)
5 밸런스/재미 — 재료를 MAX까지 키우는 도달감, 합성 보상의 가치 MAX 5까지 강화 비용/난이도가 합성 보상에 걸맞은지 (수치 조정 후보)
6 폰트 — 합성 카드 텍스트 neodgm SDF 로 표기되는지
빠른 재현 팁: 카드가 Shot/Orbital 레벨 카드로 잘 안 나오면, 강화 비용/레벨 곡선상 MAX 도달이 오래 걸릴 수 있다. 체감이 느리면 시나리오 5(밸런스)로 기록해두면 수치 조정에 반영한다.
