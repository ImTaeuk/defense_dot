TASK-014 — Arena 적 렌더·피격 이펙트 복구

원인 분석 정리 완료 · 연출/커밋 대기 2026-06-23 → 갱신 2026-06-29

1. 제보 요지

투사체 교체(Projectile_Water)·적 3D화(Sweeper) 이후 "피격 이펙트가 둘 다 사라졌다"는 보고로 시작. 추적 과정에서 더 근본적인 문제 — 적 본체가 검은 실루엣으로만 렌더되는 현상 — 이 드러났다. 또한 추적 중 임의로 추가했던 흰색 번쩍임에 대해 사용자가 "부탁한 적 없다"고 지적.

핵심 결론: 적 검은 실루엣의 정체는 BA_ToonLit 셰이더의 ForwardLit(본체) 패스가 적 Sweeper 메시에서만 그려지지 않는 것. 정확한 메커니즘은 미규명이나, 적 머티리얼을 URP/Lit 로 교체해 우회 해결.

2. 현재 동작 (증상 재현)

  1. 코어 타워가 투사체 발사 → 투사체가 적에 명중 (ProjectileEffect.cs:Update, 적 hp 감소 확인됨 — 명중 자체는 정상)
  2. 명중 시 VfxPlayer.SpawnOneShot(hitVfxPrefab) 분기 통과 못 함 → 폭발 VFX 안 나옴
  3. 적 본체가 검은 실루엣으로만 표시 → 색·피격 반응·사망 연출 전부 묻힘
  4. (추적 중 추가됐던) 흰색 emission 번쩍임 → 사용자 미요청 사항

3. 근본 원인

원인 ① 명중 폭발 VFX 부재

Assets/Prefabs/Abilities/Projectile_Water.prefab · ProjectileEffect
// 명중 처리부 — hitVfxPrefab 이 null 이라 분기 통과 못 함
if (hitVfxPrefab != null)   // null → 폭발 VFX 스킵
    VfxPlayer.SpawnOneShot(hitVfxPrefab, transform.position, Quaternion.identity);

원본 Hovl 프리팹의 자체 명중 스폰 스크립트(HS_ProjectileMover)를 제거하면서, 대체할 hitVfxPrefab 을 비워둔 것. → Hit_Water 복사·배선으로 해결.

원인 ② 적 검은 실루엣 (핵심)

Assets/ExternalResources/BlueArchive/Aris/Shaders/BA_ToonLit.shader
// frag 를 강제 단색으로 바꿔 패스 렌더 여부 테스트
half4 frag(Varyings IN) : SV_Target {
    return half4(0,1,0,1);   // Aris=초록 적용 / 적=검정 → 적은 패스 자체 누락
}

같은 BA_ToonLit 셰이더인데 큐브·Aris 메시에선 ForwardLit 이 정상, 적 Sweeper 메시에서만 누락되어 Outline(검정) 패스만 남는다. 셰이더·머티리얼·MPB·스케일 등 모든 변수를 배제했으나(아래 5절) 정확 메커니즘은 도구로 규명 못 함.

초기 진단(06-23)은 "_HitFlash MPB 가 SRP Batcher 에 무시됨"으로 봤으나, MPB→material 전환 후에도 적은 검정이었음 → MPB 는 무관, 진짜 원인은 ForwardLit 패스 누락이었다.

4. 기획 요구사항 (사용자 확정)

  • 흰색 번쩍임(emission)은 요청한 적 없음 → 제거.
  • 피격 이펙트는 Hovl 피격 파티클 사용 → Hit 9 water 선택.
  • 명중 파티클이 게임에서 안 보이는 것은 "배경 이미지 작업을 아직 안 한 게 문제, 일단 이대로 갈게" — 파티클 변경 없이 진행.
  • 커밋은 보류(요청 시 진행).

5. 배제 검증 — 진단 매트릭스

적 검은 실루엣의 원인을 좁히기 위해 가능한 변수를 순차 배제했다. 결론: 적 Sweeper 메시 + BA_ToonLit ForwardLit 조합만 실패, URP/Lit 은 정상.

검증 항목결과
셰이더 자체 (큐브 + BA_ToonLit)정상 — 민트색 렌더
Aris 메시 + BA_ToonLit정상
적 메시 + URP/Lit정상 (빨강 테스트)
머티리얼(에셋 / new Material), MPB, _DissolveTex무관 — 전부 검정 유지
GPU skinning (off 포함), bounds / updateWhenOffscreen무관
ForwardPlus 키워드 (_CLUSTER_LIGHT_LOOP) · instancing 보강무관 — 효과 없음
DepthOnly · ShadowCaster 패스 추가무관 (depthPriming=Disabled)
스케일(589배) · 메시 import(normals/optimizeMesh/RW) · vert 변환무관
결론: 같은 적 메시에 URP/Lit 은 정상 렌더되므로, BA_ToonLit ForwardLit 패스 누락을 직접 고치는 대신 적 색 머티리얼을 URP/Lit 로 교체해 확실히 우회한다.

6. 해결 방안 — 변경 사항

(1) 적 색 머티리얼 — BA_ToonLit → URP/Lit 수정 필요

Assets/ExternalResources/BlueArchive/Sweeper/Sweeper_{Mint,Pink,Yellow}.mat
▼ BEFORE
shader: DefenseDot/BA_ToonLit   // ForwardLit 패스가 적 메시에서 누락 → 검은 실루엣
_BaseMap: (Sweeper 텍스처)
▼ AFTER
shader: Universal Render Pipeline/Lit   // 적 메시 정상 렌더 확인됨
_BaseMap: (Sweeper 텍스처) — 유지

적이 색(Mint/Pink/Yellow)으로 정상 표시. 대가로 BA_ToonLit 고유의 toon 음영·외곽선·dissolve 는 사라짐(아래 7절 참고).

흰색 번쩍임을 들어내고, 적 피격 반응은 명중 폭발 파티클(아래 3번) 로 일원화. 사망 연출은 셰이더 dissolve 대신 스케일 축소로 대체.

(3) Projectile_Water — hitVfxPrefab 배선 완료·유지
