분류 보고서 active 12건 분석 완료 · 2026-07-07

1. 개요 — 무엇을 분류했나

docs/tasks/active/ 의 미완료 Task 문서 12건을 전부 읽고, 각 문서의 상태·우선순위·남은 작업량(볼륨)·상호 흡수 관계를 기준으로 분류했다. done 폴더의 TASK-002·013 은 이미 완료되어 제외했다.

핵심 결론: 문서 12건 ≠ 유효 작업 12건. TASK-012(Arena 로드맵)가 마스터 문서로 010·011·001-B 를 흡수했고, TASK-004(디버그 공격)는 TASK-010 A-2 에서 삭제 예정(throwaway) 으로 명시되어 있다. 실제 굴러가는 축은 Arena 코어(012) + 전투 연출·인프라(014/015/016) + Grid 갈래(005) 로 좁혀진다.

4. 우선순위별 상세

① 높음 — Arena 코어와 전투 연출

  • TASK-012 Arena 로드맵 — 마스터 문서. A0~A3(종료규칙·능력데이터·자동전투·레벨업카드) 코어 완료. 남은 것: A4 인게임 강화 · A5-1 능력 조합 · A6 보스 · A7 메타층 8종 · A8 계보 공명 · B HUD 리스킨. 볼륨이 압도적이라 Phase 단위로 쪼개 진행 필요.
  • TASK-014 전투 VFX — B-0(unscaled time)·B-3(피격 파티클 확대) 완료. 남은 것: B-1 시전 차징 연출 · B-2 타격감(히트스톱·카메라 셰이크). 변경 전부 미커밋.
  • TASK-015 Addressables — 구현·검증 완료. 남은 C-2(Addressables Build 산출)는 배포 시점 처리. 사실상 닫아도 되는 상태.
  • TASK-004 디버그 공격 — A1~A4 구현이 남았으나, TASK-010 A-2 가 이 3종(단일/범위/투사체)을 Skill 로 대체·삭제 하기로 명시. 능력 시스템(012 A2)이 이미 완료돼 존재 의의를 재검토해야 한다 → §5 참조.

② 중간 — Grid 갈래와 구조 정리

  • TASK-005 Grid 타워 — SP1 빌드 모달 완료. 남은 SP2(관리 모달·업그레이드·판매) · SP3(다종 타워·밸런싱). Arena(012)와 별개 갈래.
  • TASK-016 코어 프리팹 — 런타임 Destroy(debugBt) 땜빵을 코어 전용 프리팹으로 정리. 독립 실행 가능, 볼륨 작음.
  • TASK-008 진입·일시정지 — 타이틀·모드 선택 · Pause · 웨이브 딜레이. 독립적 편의 계층.
  • TASK-006 Actor Animator — 보류. 방식 결정(Cainos 재활용 / 전용 컨트롤러 / 경량 플레이어) 선행 필요 → §5 참조.
  • TASK-010 Skill 시스템 — 런타임·정의·장착은 012 A1·A2 로 흡수·커밋됨. 남은 것: 가챠 획득 · 디버그 공격 대체. 사실상 012 로 수렴 중.
  • TASK-001 아레나 맵 — A-1 HUD 결선(코드 준비 완료, 프리팹만)은 012 A0 에 흡수, B(동적 크기)는 원작에 없어 보류. 거의 소멸.

③ 낮음 — 부채·장기

  • TASK-009 코드 정리 — JPS dead code 제거 · 빈 껍데기 보완 · Panel_Grid→Panel_HUD 리네임. 저위험·저볼륨, 틈새 처리용.
  • TASK-011 메타 상점 — 스타더스트·강화소·영구 업그레이드. Arena 방향(메타 진행형 a) 확정 시에만 우선순위 상승. 012 A7 로 흡수, 최장기.
