1. 개요 — 갱신 내용

이전판 대비 TASK-002(게임 종료·결과·재시작) 가 빠졌다. 구현·검증이 모두 끝나 docs/tasks/done/ 로 이관됐기 때문이다. 남은 활성 TASK 11개를 우선순위 × 소요시간으로 다시 비교한다.

핵심 결론: 단기 Quick Win(고우선·저공수)은 이제 TASK-014 → TASK-004. TASK-012(Arena 로드맵) 한 건만 고우선·초대형(2주+)으로 별도 트랙이다.

2. 소요시간 추정 기준

TASK 문서에는 소요시간이 명시되어 있지 않아, 남은 미완료 항목 수 × 작업 성격으로 1인 작업(코드 + Unity 검증 포함) 기준 추정했다. 같은 항목 수라도 "디자인 결정 선행" 은 순수 코드보다 길고 불확실하다.

5. 사용자 직접 검증·완료 처리 트랙

구현은 끝났고 사용자만 할 수 있는 수동 검증만 남은 항목은 개발 남은작업과 분리해 별도로 관리한다. 숨기지 않고 "검증하고 닫으라"고 알린 뒤, 검증 완료 시 done/ 으로 이관한다.
