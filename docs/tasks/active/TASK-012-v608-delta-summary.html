1. 요청 요지

레퍼런스 웹게임(Assets/Reference/dot-defense-main/index.html)이 갱신되었다. "시스템적으로 무엇이 바뀌었는지" 원작을 다시 분석하고, 그 결과를 ① 개발비용 ② 개발중요도 두 기준으로 분류하여 요약한다. 분석 결과는 로드맵 TASK-012 에 반영했다.

결론: 직전 커밋본 v480 → 현재 v608 (버전 128 증가). diff +3,155 / −599줄. 신규 6 · 변경 4 = 총 10개 시스템이 추가/대폭 변경됨. 핵심 가성비 1순위 = 순수 패시브 4종(저비용·고중요), 최대 공수 = HUD 리스킨 · 계보 공명.

7. 권장 작업 순서

  1. A3 (레벨업·카드 허브) 완성 — 기존 진행 중. 모든 능력 콘텐츠의 진입점.
  2. A5-2 순수 패시브 4종 — A3 직후 끼워넣기. 데이터 4개+곱연산 1곳, 빌드 밸런스 즉시 향상.
  3. B (HUD 리스킨) — A3 UI 시점에 arena-hud-replacement 진행분과 합쳐 일괄 적용.
  4. A4(강화) → A5-1(조합) → A6(보스) — 코어 루프 완성.
  5. A7 메타군 — 행성난이도·승천완화 우선, 계정레벨·업적·기록은 후순위, 글로벌 랭킹은 서버 준비 후.
  6. A8 계보 공명 — A7 가챠/진화 인프라 완성 후 최후미. 비주얼 메커닉 공수 큼.

8. 요약

원작 v480→v608 갱신의 본질은 ① 메타/진행 레이어 대폭 강화(행성난이도·계정계급·업적·기록·랭킹) ② 전투 깊이 추가(순수 패시브 4종·계보 공명) ③ UI 전면 리스킨(SF 메카닉 HUD). 코어 전투 규칙(웨이브·패배·조합·유물·승천)은 구조 불변 — 기존 TASK-012 A0~A7 골격은 유효하며, 신규분은 A5-2·A7-4~8·A8·B로 흡수했다.

Unity 이식 관점 핵심: 신규 시스템 대부분은 데이터 주도(저~중 비용)라 싸게 옮겨지고, 진짜 공수는 HUD 리스킨과 계보 공명의 비주얼 메커닉에 집중된다. 가성비 최우선은 순수 패시브 4종.
