## 1. 배경

볼륨이 커 012 로드맵에서 이 문서로 분리한다(2026-07-20 결정).

**"한 판(런)"은 이미 성립**한다(성장 3단 A3·A4·A5-1 완료). 메타층은 **런과 런 사이·런 밖의 성장·콘텐츠**로, 지금은 통째로 없다.

## 3. 계보 공명 (A7-9) — 우리 계보와의 차이

혼동 방지를 위해 명시한다. **우리가 구현한 A5-1 계보(능력 합성)와 A7-9 계보 공명은 다른 층이다.**

| | A5-1 능력 합성 (구현됨) | A7-9 계보 공명 (미구현) |
|---|---|---|
| 대상 | 능력 A + 능력 B → 능력 C | 캐릭터 SR + 캐릭터 SSR → 시그 능력 각성 |
| 트리거 | 재료 2개 MAX → 합성 카드 선택 | 진화 정점 도달 시 일시정지 이벤트 팝업 (게임당 1회) |
| 효과 | 재료 소진, 결과 능력 획득 | 시그니처 능력 영구 강화 |
| 콘텐츠 | 레시피 데이터 | 조합별 고유 이름 + 대사 2줄 + 축(axis) + SR·SSR 초상화 |
| 축(axis) | 없음 | blast·pierce·shock·ice·echo 5종 |

- 원작 근거: `Assets/Reference/dot-defense-main/index.html:28644` (`LINEAGE_RESONANCE`), `:28581` (`openLineageResonanceEvent`)
- **가챠(A7-1)로 캐릭터를 얻는 구조가 있어야 SR+SSR 조합이 성립**하므로 메타층에 종속.
