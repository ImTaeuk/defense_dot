defense_dot — 남은 TASK 정리 (백로그 오버뷰)

백로그 정리 현재 상태 반영 2026-06-11

1. 개요 — 지금 어디까지

현재는 코어 전투 루프의 스켈레톤 + 모드별 타워 배치 일부가 동작하는 단계다. 완료·커밋된 기반: 아레나 맵·모드 합성 루트, 공통 HUD, 디버그 공격(단일/범위/투사체), Arena 중앙 타워, Grid 슬롯 빌드 모달(SP1).

남은 큰 줄기 5개: ① 플레이 루프 클로징(TASK-002) · ② 타워 시스템 확장(TASK-005) · ③ Actor BT/애니(TASK-006+BT) · ④ Arena 맵 마무리(TASK-001) · ⑤ 메타/콘텐츠(가챠·강화소). "게임이 성립하는가"(①)가 최우선.

3. TASK-002 — 플레이 루프 완성 높음

"시작 → 플레이 → 다시 시작"의 완결 루프가 아직 닫히지 않았다. (코드 직접 검증 기준)

문서 작성 이후 이미 해소된 항목: 타워 프리팹 부재(P0-1, Tower_Test 존재), Grid 배치 불가(SP1으로 해결), CoreDamage 하드코딩(P2-2, EnemyData 이관 완료).

분류남은 작업비고
P1 루프 클로징결과 패널(승/패) + 재시작 — GameResultPresenter(OnPhaseChanged 구독)·결과 프리팹·SceneManager.LoadScene이벤트 이미 존재, 소비자만 추가
P1 모드 종료Arena 무한화 — 유한 웨이브 소진 시 잘못된 Victory 발생 방지(원작=무한 생존)원작 불일치(F3)
P1 정지게임오버 후 스폰·입력 정지—
P3 진입/폴리시타이틀 + 모드 선택(Arena/Grid), 일시정지(Time.timeScale), WaveData.nextWaveDelay 적용—
C 정리JPS PathfindingService dead code 정리, ActorBase.Initialize/Die 빈 껍데기, Panel_Grid→Panel_HUD 리네임일관성
결과 화면+재시작이 없으면 막다른 길 — 게임 성립의 마지막 관문. Grid는 이거면 루프 완결, Arena는 (a/b) 방향 결정 후 확정.

4. TASK-005 — 타워 등장·배치 시스템

완료: A-1(Arena 중앙 타워), B-1(Grid 결선), B-2(구매·선택 UI = SP1 빌드 모달).

항목내용상태
SP2점유 타워 클릭 → 관리 모달(업그레이드·판매). SP1 의 OnSlotSelected 파이프라인 재사용미착수
SP3타워 다종(B-3)·비용·스탯 밸런싱미착수
C. Skill 시스템원작 가챠·능력(ability) — 슬롯 클릭 시 3장 카드 뽑기. TowerActor 디버그 공격 토글(단일/범위/투사체)을 정식 Skill 로 대체·삭제, aoeRadius 등 임시 필드 이관설계 등록됨
D. 메타 상점강화소(스타더스트 영구 업그레이드) — 장기장기
원작의 "타워 건설"은 곧 가챠+능력(Skill)이다 — SP1 은 그 파이프라인 토대(고정 목록 임시 상점)이고, Skill(C) 구현 시 모달 내용을 가챠로 교체하면 원작에 수렴한다.

5. Actor BT + Animator (TASK-006 & BT 프레임워크)

Actor 행동을 풀 Behavior Tree로 구동하고 애니메이션이 ActorState를 반영하는 단방향 파이프라인. 다른 세션에서 진행 중 — Phase 1 코드는 구현됐으나 미커밋.

단계내용상태
BT Phase 1순수 POCO BT 프레임워크(BTNode·Blackboard·Selector·Sequence·리프) + EditMode 테스트구현됨·미커밋
BT Phase 2통합 리팩토링 — TowerActor/MonsterActor 자체 Update 루프를 BT로 이관, 자가-SetState 제거(단일 writer)미착수 (회귀 주의)
BT Phase 3ActorAnimatorBinder + AnimatorController 에셋 + 프리팹 배선미착수
TASK-006 애니방향(N/S/E/W)·걷기 애니 미반영 해결 — 방식 결정(Cainos AC Player 레이어 weight 제어 / 전용 컨트롤러 / 경량 플레이어)보류
빌보드(BillboardSprite CameraPlane)·카메라 중앙 주시는 정상 — 애니메이션만 남은 격리 작업. BT Phase 2는 최근 커밋된 TowerActor(디버그 공격·치트)와 맞물려 회귀 주의.

6. TASK-001 — Arena 맵 시스템 (마무리)

핵심 시스템·리팩토링·HUD 통합은 완료·커밋. 남은 것은 결선과 미래 항목.

항목내용상태
A. Arena HUD 결선Panel_Arena 프리팹 신설·씬 결선 (capacity 공급 코드는 이미 커밋). designer 작업코드 준비됨
B-1. Arena 코어 강화원작 능력·가챠 — ArenaModeBootstrap 소유 자리. 게임 디자인 결정 필요미래
B-2. 동적 아레나 크기ArenaModel.Expand/Shrink·OnRadiusChanged 훅 존재, 트리거(보스 등장 등) 미연결미래(훅 있음)
B-3. 코어 비주얼헥사 링·펄스 등 ArenaView 장식미래
