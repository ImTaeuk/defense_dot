4. 기획 요구사항 (사용자 확정)

4개 항목을 선택지로 제시했고, 사용자는 전 항목에 대해 동일한 답을 확정했다.

  • 반영 범위 — "모든 충돌 또는 신규 작업은 언급한 파일 기준으로 최신화 해." → A·B·C·D 전 섹션 반영
  • GetComponent 강도 — "명시한 파일 기준으로 최신화" → 금지로 격상
  • 임시 컬렉션 판단축 — "명시한 파일 기준으로 최신화" → escape 기준 채택
  • 권한 규칙 충돌 — "명시한 파일 기준으로 최신화" → 금전·손상 예외 추가
즉 판단 기준은 일관되게 "포터블 문서가 이긴다"이다. 다만 위 3-(B) 의 주석 항목처럼 충돌로 보였으나 실제로는 대상이 다른 규칙인 경우는 덮어쓰면 정보가 소실되므로 예외로 두고 이 문서에 명시했다.

후속 확정 — GetComponent 강도 재조정 1차 반영 후 정정

1차 반영에서 GetComponent 를 포터블 기준의 "금지" 로 격상했으나, 사용자가 "getcomponent 금지까지는 아니긴 했는데" 로 정정했고 재확인 결과 아래로 확정했다.

  • GetComponent — 개정 전 문구인 "지양" 그대로 복구. lint 도 위반이 아닌 검토 플래그로 환원
  • 초기화 과정의 AddComponent — 조항 자체는 남기되 "금지" → "지양" 으로 완화해 유지
  • UI 제어 컴포넌트 조항(드롭다운 등을 하위 오브젝트로 추가하고 [SerializeField] 로 참조) — "지양" 기조와 모순이 없어 그대로 유지
이 정정으로 "모든 충돌은 포터블 기준" 원칙에는 예외 2건이 생겼다 — ① 주석 강도(대상이 다른 규칙) ② GetComponent 강도(사용자 재확정). 나머지 항목은 모두 포터블 기준 그대로다.

(2) 전역 CLAUDE.md — 성능(LINQ · 임시 컬렉션 · 캐싱) 수정 필요

~/.claude/CLAUDE.md · 「코딩 컨벤션 > 성능」
▼ BEFORE
- **런타임 predicate LINQ 금지** (`.Any(x => )`, `.Where`, `.Select` 등) — 델리게이트/이터레이터 GC 할당이 스파이크를 만든다. `foreach` + `continue` 가드로 대체한다. **Editor 코드와 저빈도 초기화 경로는 예외**
- 임시 컬렉션: 함수 스코프 임시 컬렉션은 `new` / 필드 캐싱 / `ListPool` **세 가지를 호출 빈도로 비교해서 고른다**. 한 곳에서만 쓰는 의존성은 필드 캐싱 없이 직접 호출한다. 필드로 보관하는 컬렉션은 일반 new 허용
▼ AFTER
- **런타임 predicate LINQ 금지** (`.Any(x => )`, `.Where`, `.Select`, `.FirstOrDefault`, `.All` 등) — 모델·시스템·네트워크 응답 핸들러 같은 런타임 경로에서 쓰지 않고 `foreach` + `continue` 가드로 대체한다. **무인자 `.Any()`(비었는지 확인) 도 금지** — `.Count` 비교나 직접 검사로 대체. **Editor 코드와 로딩·초기화 같은 저빈도 1회성 경로는 예외**
  - 이유: LINQ 의 호출당 힙 할당(클로저·이터레이터·델리게이트·박싱)이 Unity 의 비세대·비압축 Boehm GC 와 만나 stop-the-world GC 스파이크 → 프레임 히칭. 본질은 CPU 비용이 아니라 **GC 할당 압력**
- 임시 컬렉션: 함수 스코프 임시 컬렉션(`List<T>`/`HashSet<T>`/`Dictionary`/`StringBuilder`)은 `new` / 필드 캐싱 / `ListPool` **세 가지를 동시에 비교해서 고른다**
  - **1차 판단축은 escape 여부** — 함수 스코프 밖으로 escape 하지 않으면 **풀링이 최우선**. escape 하거나 비동기 흐름을 가로지르면 풀링 부적합
  - 2차 판단축은 호출 빈도 — escape 하지 않더라도 저빈도 1회성 경로면 `new` 로 충분한지 함께 본다
  - 풀 사용 시 **블록 `using` 필수**. 필드로 보관하는 컬렉션은 일반 new 허용
- 단발 의존성 캐싱 금지: 한 곳에서만 호출하는 의존성은 사용 지점에서 직접 호출한다. **호출이 2개 이상 메서드·분기에 흩어져 있을 때만** 캐싱을 고려한다

- switch: … `default` 는 인자 이름·실제 값·메시지를 모두 담아 던진다 (`throw new ArgumentOutOfRangeException(nameof(param), param, "처리되지 않은 값입니다.");`)
